트렌드 존 관리

편집 중

트렌드 모드에서 지도의 헥사곤을 선택하면 새 존을 만들 수 있어요. 목록 카드 스타일은 🖥 화면·디자인 › 📐 표시 옵션에 있어요.

피드 사진

사진을 올리면 피드 탭에 노출돼요. 각 사진의 트렌드존을 지정하면 동(구역)이 자동으로 채워져요. 보이는 방식(그리드 열·시간)은 🖥 화면·디자인 › 📐 표시 옵션에, 지도 아이콘 크기는 🖥 화면·디자인 › 🧷 지도 컨텐츠 표시에 있어요.

소셜 컨텐츠 (채팅방)

주제방/프라이빗은 관리자만 개설·수정(전체 공유). 동네 채팅 기본 대화는 JSON [{"who":"닉","t":"내용"}] 또는 CSV(닉,내용 한 줄씩)로 채워요.

요약 공간 지면 (탭별 이미지)

상단 요약 공간에 노출할 UI 목업 이미지. 각 이미지의 탭(지도/피드/소셜)을 지정하면 해당 탭에서만 보여요. 피드 컨텐츠와는 별개. 카드 스타일은 🖥 화면·디자인 › 📐 표시 옵션에 있어요.

지역 시드 생성

지금 보고 있는 지역 반경 안의 실제 장소를 찾아(Places) 그 상호로 컨텐츠를 만듭니다. 문구는 AI 에이전트가 쓰고, 응답을 못 받으면 장소 종류별 기본 템플릿으로 채워요. 한 번의 생성이 그룹 하나가 되고, 아래 목록에서 그룹째 숨기거나 지울 수 있습니다. (기존 🌱 채우기/🧹 비우기와는 별개 — 서로 건드리지 않아요.)

데모 데이터 (강남·잠실·성수)

실제 유저들이 쓰는 것처럼 보이는 가상 컨텐츠(3지역: 피드 40·스팟 30·Request 4·채팅)를 공유 컬렉션에 채워요. 이미지=실사진 링크(Wikimedia). 소유자=shoomerion@gmail.com(해당 계정으로 수정·이동 가능). 존 카드 편집/피드 관리에서 URL 교체 가능.

수량=지역별 균등 샘플링 비율, 밀집도=지역 중심 기준 퍼짐 정도(동 라벨 자동 재판정). 수량을 줄여 다시 채울 땐 🧹 비우기 먼저.

디자인

v3.0은 석촌동 에셋 기준 재설계(웜 오프화이트 + 코랄 · °C 지표)로, 폰 화면뿐 아니라 이 콘솔 화면까지 함께 바뀝니다 — 핸드오프가 웹앱과 콘솔을 같이 그렸기 때문이에요. v2.0은 시안 스킨(폰 화면만). 고르는 즉시 바뀌고, 저장하면 모든 사용자에게 반영돼요. 문제가 생기면 기존(Legacy)으로 되돌리면 v1.77 화면 그대로입니다.

🔊 효과음

비워 두면 저장소의 기본 소리(sfx/ 폴더)가 납니다. 받는 주소는 sfx/이름.wav(저장소 파일) · https://… · data:audio/… 셋입니다. 정한 값은 📋 설정 JSON 복사 → settings-default.json 으로 넣어야 처음 여는 기기·데모 임베드에도 갑니다. 개별 데모가 persona-vc 콘솔에서 제 소리를 올리면 그 자리만 덮어씁니다.
